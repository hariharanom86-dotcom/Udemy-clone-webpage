# Udemy Clone – Online Learning Platform UI

A front-end website inspired by Udemy, built using HTML5 and CSS3. This project showcases a clean and organized online learning platform interface featuring course categories, recommended courses, popular courses, search bar, and a navigation menu.

## Features

* Responsive-style navigation bar with a search field.
* Course categories and recommended course sections.
* Popular courses with images, ratings, and pricing.
* Technology topic recommendations.
* Structured footer section.
* Flexbox-based layouts for arranging content.
* Custom styling with Google Fonts and Font Awesome icons.

## Technologies Used

* HTML5
* CSS3
* Flexbox
* Google Fonts
* Font Awesome

## Project Purpose

This project was created to practice and improve my front-end web development skills, particularly HTML structure, CSS styling, Flexbox layouts, and webpage design.
